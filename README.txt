# 🧮 Calculator Web App

A simple and interactive **Calculator Web App** built using **HTML, CSS, and JavaScript**. The application provides a clean user interface and supports basic arithmetic operations.

## 🚀 Features

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)
* Percentage (`%`)
* Decimal calculations
* `AC` button to clear the display
* `DEL` button to delete the last entered character
* `00` and `0` input support
* Interactive button-based calculation

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and user interface
* **JavaScript** – Calculator logic and button interactions

## 💻 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/calculator-web-app.git
```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using the calculator.

## 🎯 Project Objective

The main objective of this project was to practice **HTML, CSS, and JavaScript fundamentals** by building an interactive calculator with event-based user interactions.
